# Characterization quirks log

Behaviours of the current `audio_control.c` that were surprising when the
golden traces were first read. Each needs a decision before the rewrite:
**preserve** (the rewrite must reproduce it) or **fix** (the rewrite changes
it deliberately, with a reviewed golden update).

Status: `confirmed` = visible in a committed golden trace;
`suspected` = seen in code review, not yet pinned by a scenario.

| 8 | confirmed (`alarm-exact-crossing`) | Alarm crossing uses a half-open interval (`>= min && < max`).
